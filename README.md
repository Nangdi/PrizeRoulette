# PrizeRoulette

과학탐구관 개관 행사(2026-11-24, 11-28, 11-29)용 모바일 경품 룰렛.
부스에 인쇄된 고정 QR을 찍으면 룰렛을 1회 돌리고, 결과 화면을 스태프에게 보여 준 뒤 경품을 받는다.

```
SNS 구독 → 스태프가 구독 확인 → 인쇄 QR 촬영 → 룰렛 1회 → 결과 화면 제시
  → 스태프가 그 폰에서 [스태프 수령 확인] + PIN → "수령 완료" 도장 → 경품 지급
```

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 관람객 화면(룰렛, 결과, 수령 처리). GitHub Pages로 배포 |
| `apps-script/Code.gs` | 서버. 구글 시트에 붙인 Apps Script 웹 앱 |
| `tools/mock-gas.js` | 시험용 가짜 Apps Script 환경 (`index.html?mock=1`) |
| `tools/test.py` | 자동 시험(수량·중복·수령·화면) |
| `tools/loadtest.py` | 배포한 서버 동시 요청 시험 |

## 동작 규칙

- **추첨은 서버가 한다.** 날짜별 재고(남은 수량) 비율로 뽑는다. 재고를 다 쓰면 등수별 수량이 정확히 설정값과 같다.
- 추첨·수령은 ScriptLock 안에서 한 명씩 처리해 동시에 돌려도 1등이 수량보다 많이 나오지 않는다.
- **1회 제한은 "오늘 + 기기 키"** 기준이다. 기기 키는 처음 접속한 브라우저에 저장된다.
  같은 브라우저로 다시 열면(새로고침, 재스캔) 새로 뽑지 않고 이전 결과를 "다시 보기"로 보여 준다.
- 결과 화면의 **현재 시각은 1초마다 바뀐다.** 멈춰 있으면 캡처 화면이다.
- 수령 처리하면 서버에 수령 시각이 기록되고 화면에 "수령 완료" 도장이 찍힌다. 다시 열어도 도장이 남는다.
- 재고 탭에 오늘 날짜 줄이 없으면 "운영일이 아니에요", 재고가 0이면 "오늘 이벤트가 마감되었어요"가 뜬다.

### 막지 못하는 것 (스태프 판단)

- 다른 앱·브라우저·시크릿 창으로 다시 찍으면 새 참여가 된다. 수령할 때 "다시 보기" 표시와 얼굴로 판단한다.
- 결과 화면을 다시 띄우지 못하면 지급하지 않는다(부스 안내).

## 시트 구성 (setup() 실행 시 자동 생성)

| 탭 | 내용 |
|---|---|
| 설정 | `수령 PIN`, `1등 경품` ~ `4등 경품` |
| 재고 | `날짜 | 1등 | 2등 | 3등 | 4등` 남은 수량. 추첨할 때마다 줄어든다 |
| 기록 | `참여번호 | 날짜 | 시각 | 기기키 | 등수 | 수령시각` |

- 경품명, PIN은 시트에서 바로 고치면 다음 요청부터 반영된다.
- 행사를 일찍 닫으려면 재고 탭의 그날 수량을 0으로 바꾼다.

## 서버 배포 (구글 시트 + Apps Script)

1. 구글 드라이브에서 새 스프레드시트를 만든다.
2. `확장 프로그램 → Apps Script`를 열고 `Code.gs` 내용을 `apps-script/Code.gs`로 바꿔 넣고 저장한다.
3. 함수 선택에서 `setup`을 고르고 실행한다(처음엔 권한 승인). 시트에 탭 3개가 생긴다.
4. 설정 탭에서 **수령 PIN**과 **경품명**을 고친다.
5. `배포 → 새 배포 → 유형: 웹 앱`
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 `index.html`의 `API_URL`에 넣는다.

`Code.gs`를 고친 뒤에는 `배포 → 배포 관리 → 수정 → 버전: 새 버전`으로 다시 배포해야 반영된다(주소는 그대로).

## 화면 배포 (GitHub Pages)

1. GitHub 레포 `Settings → Pages → Branch: main / (root)`.
2. 주소 `https://nangdi.github.io/PrizeRoulette/`로 QR을 만들어 인쇄한다.

## 시험

```
python tools/test.py           # 로직 + 화면 자동 시험 (Playwright, 설치된 Chrome 사용)
python tools/test.py --shots   # 화면 캡처를 tools/shots/에 저장
```

브라우저로 직접 보려면 레포 폴더에서 `python -m http.server 8000` 후
`http://localhost:8000/index.html?mock=1` (서버 없이 Code.gs를 브라우저에서 실행).

- `&reset=1` 가짜 시트 초기화, `&stock=0,0,0,1` 오늘 재고 지정

배포 후 동시 요청 시험(실제 시트 재고를 씀 → 시험 날짜 줄로 하고 끝나면 지운다):

```
python tools/loadtest.py https://script.google.com/macros/s/…/exec 30
```

## 행사 전 점검

- [ ] 재고 탭 날짜·수량(10/40/150/500), 시험 줄 삭제
- [ ] 기록 탭 시험 기록 삭제
- [ ] 수령 PIN 변경, 경품명 입력
- [ ] 인쇄 QR로 아이폰(카메라)·안드로이드(카메라)·카카오톡 스캔 확인
